Home Network Devices: Home Gateway, PC, Laptop, Smartphone (optional). Steps Open Packet Tracer. Add a Home Gateway. Add a PC and Laptop. Connect PC to Home Gateway using a copper straight-through cable. Connect Laptop wirelessly: Laptop → Desktop → PC Wireless Select the Home Gateway's Wi-Fi network. Open Home Gateway → GUI or Config. Enable DHCP. Set the wireless SSID and password if required. On the PC, go to Desktop → IP Configuration → DHCP. Check that the PC receives an IP address automatically. Test: Open Command Prompt and ping the gateway IP. IoT System Devices: Home Gateway, Smart Lamp, Smart Fan, Smart Door (or other IoT devices). Steps Add a Home Gateway. Add IoT devices such as Smart Lamp and Smart Fan. Click each IoT device → Config. Set the wireless connection to the Home Gateway. If required, configure the IoT server or registration settings. Open the Home Gateway's IoT interface. Register or connect the IoT devices. Open the device control interface. Turn the lamp or fan ON/OFF. Verify that the device responds.
